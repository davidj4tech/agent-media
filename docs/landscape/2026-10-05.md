# Landscape watch — 2026-10-05

Scope: `gh` for the six GitHub entries (window: since 2026-09-28), WebSearch and
the Claude Code changelog for the rest, plus discovery. All six repos still
exist at the watchlist names; none moved or archived.

## Worth stealing

- **Read receipts that mean "the agent started on it".** Claude Code 2.1.285
  fixed Remote Control marking a message read the moment it arrived rather than
  when Claude began work, and fixed queued messages being lost on quit (they now
  arrive on next resume) ([changelog](https://code.claude.com/docs/en/changelog)).
  Touches: Sasonica's sent/heard state and the relay (roadmap item 16) — delivery
  vs. "picked up" are different states worth showing separately on the phone.
- **Bounded reconnect instead of silent stalls.** 2.1.288: Remote Control gave no
  messages "for minutes" when reconnect requests got no reply; it now gives up
  after 30 s and retries, and keeps the session through credential renewal
  ([changelog](https://code.claude.com/docs/en/changelog)). Touches: the hosted
  relay's WebSocket doorbell and phone-jobs worker — hard per-attempt timeouts.
- **Stacked permission prompts: "2 of 5", oldest first.** 2.1.286 numbers
  queued prompts and shows the oldest first so a new one doesn't cover the one
  being read ([changelog](https://code.claude.com/docs/en/changelog)). Touches:
  ask cards when several arrive while the phone is locked.
- **Idle notifications must know about background agents.** 2.1.287 stopped
  `idle_prompt` hooks firing while background agents still run, and 2.1.288 caps
  background shells at 30 min (max 2 h) with a notice to the model
  ([changelog](https://code.claude.com/docs/en/changelog)). Touches: our
  Stop/Notification speech hooks — don't announce "done" while work continues.
- **Multi-select delete in a session list.** claudecodeui can select and delete
  several of a project's sessions at once
  ([PR #1404](https://github.com/siteboon/claudecodeui/pull/1404)) and reports
  turns driven by the Claude CLI as running
  ([#1394](https://github.com/siteboon/claudecodeui/pull/1394)). Touches:
  Sasonica's session list and the "headless vs. pane" running state.

## Suggested additions

- [getpaseo/paseo](https://github.com/getpaseo/paseo) — self-hosted app for
  Claude Code, Codex and OpenCode with on-device speech and push notifications;
  pushed 10-04. The closest like-for-like to Sasonica's voice plus phone angle
  ([site](https://paseo.sh/codex)). Add to "Agent phone / remote UIs".
- [maxanatsko/agentic-voice](https://github.com/maxanatsko/agentic-voice) —
  local TTS bridge exposed three ways (MCP tool, CLI, lifecycle hooks) for
  Claude Code and Codex; useful to compare against our hook-owned speech.
- [beltranrengifo/agent-voice](https://github.com/beltranrengifo/agent-voice) —
  offline Piper TTS for Claude Code, Codex and OpenCode; a small, hook-based
  reference for long-reply handling.
- [gabrielpc4/agent-tts-macos](https://github.com/gabrielpc4/agent-tts-macos) —
  reads Claude Code, Codex and Cursor answers aloud with a code-switching voice
  (speaks mixed-language text); worth a look for how it handles code spans.
- TalkiTo ([Show HN](https://news.ycombinator.com/item?id=45927954)) — voice
  in/out for terminal agents with Slack/WhatsApp hooks; older, but the only
  hit pairing voice with a messaging transport.
