# Landscape watch — 2026-09-28

Scope note: `gh` for repo/PR activity, WebSearch for Anthropic's changelog and
discovery. Window is since the 2026-09-24 digest (4 days) — most watchlist
repos were quiet at the release level; the interesting activity is in
merged PRs, not tags.

## Worth stealing

- **Hosted transcription as a first-class route, not a plugin.** opencode
  merged an ElevenLabs Scribe transcription route
  ([PR #51641](https://github.com/anomalyco/opencode/pull/51641)) the same
  week Codex CLI 0.156.0 shipped voice on-by-default with an F8 toggle and a
  `/voice` settings picker. Two competitors now treat voice-in as core CLI
  UX rather than an add-on. Touches: Sasonica's voice pipeline — worth
  checking whether our mic/STT path is still the differentiator or just
  catching up.
- **A pinned Quick Settings dock, not a menu.** claudecodeui added a
  Quick Settings panel with pin-to-dock
  ([PR #1371](https://github.com/siteboon/claudecodeui/pull/1371)). Small,
  but it's the same "which controls survive on a small screen" problem as
  our ask cards and canvas chrome. Touches: phone UI layout.
- **Compare working copy against any branch, not just the tracked one.**
  claudecodeui's Source Control panel picked up arbitrary-branch diffing
  ([PR #1369](https://github.com/siteboon/claudecodeui/pull/1369)). Relevant
  if Sasonica ever grows a git panel beyond the current step list.
- **Retry and abort/error classification split apart.** opencode landed
  several PRs this week tightening retry-on-queued-read vs. abort vs. error
  ([#51635](https://github.com/anomalyco/opencode/pull/51635),
  [#51633](https://github.com/anomalyco/opencode/pull/51633),
  [#51632](https://github.com/anomalyco/opencode/pull/51632)) — the same
  three-way distinction our stop/barge-in path has to get right. Worth
  reading their PR descriptions for the failure modes they hit.
- **Managed model allow/deny lists in Claude Code itself.** v2.1.283 added
  `availableModelsMatch`/`deniedModels` managed settings
  ([changelog](https://code.claude.com/docs/en/changelog)). Not phone-shaped,
  but relevant if Sasonica Shell ever needs to restrict which models a
  connected phone can pick.
