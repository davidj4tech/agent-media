## Worth stealing

- **Replace the "send anyway?" confirm with Send anyway / Queue / Cancel.**
  When a turn has ended but background work is still running, a new message
  starts a turn that kills that work. claudecodeui had a `window.confirm` where
  a double Enter silently chose OK; it now offers a queue choice
  ([PR #1583](https://github.com/siteboon/claudecodeui/pull/1583)). Follows last
  week's "queued message must not fire while background work runs" item.
  Touches: the Sasonica composer's queued-send, and no default-destructive
  button on a phone.
- **A hook that cannot run should be able to block, not pass.** Claude Code
  2.1.295 added `onFailure: "block"` for command and HTTP hooks, 2.1.296 fixed
  managed `PreToolUse` denials that refused the call but did not end the turn,
  and 2.1.302 caps prompt/agent hooks at 12 running at once
  ([releases](https://github.com/anthropics/claude-code/releases)). Touches:
  our Stop/Notification speech hooks and the approval path; confirm a failing
  speech hook defaults to letting the turn through, and that a 12-hook queue
  cannot delay the Stop hook that speaks.
- **Reconnect after a silent drop, and relays on slow links.** paseo now
  reconnects to its Hub after a connection loss that raised no error
  ([PR #7315](https://github.com/getpaseo/paseo/pull/7315)) and connects relays
  over high-latency networks ([PR #7336](https://github.com/getpaseo/paseo/pull/7336)),
  and reports disconnected hosts inside the new-agent draft
  ([#7303](https://github.com/getpaseo/paseo/pull/7303)). Touches: the phone's
  outbound relay connection (off-the-tailnet rule): use a liveness ping rather
  than waiting for a socket error, and say in the composer when the host is
  unreachable before the user types.
- **Remote Control gets a notification channel and file-send limits.** Claude
  Code 2.1.295 fixed `PushNotification` claiming "not sent" in
  `claude remote-control` sessions right after a phone message, and files sent
  from remote sessions being refused when more than 256 went at once; 2.1.302
  fixed cloud-session cost restarting at zero after a resume
  ([2.1.295](https://github.com/anthropics/claude-code/releases/tag/v2.1.295),
  [2.1.302](https://github.com/anthropics/claude-code/releases/tag/v2.1.302)).
  Touches: our notification path and any batch attachment upload; the cost
  point is a reminder that resumed sessions should carry usage forward.
- **Instruction-only voice is unreliable; the hook owns speech.** The Rhyme CLI
  write-up
  ([openclawdatabase](https://openclawdatabase.com/news/videos/2026-08-31-rhyme-cli-agent-voice-replies/))
  and the new hook tools (see Suggested additions) agree with our design, and
  add a prompt shape: one or two sentences on what was done, then a question
  about the next step. Touches: the "short reply first" rule in
  `agent_notes.md`; this already matches, so it is confirmation, not a change.
