**The remaining problem is observation cost, not correctness.** From red5 each
snapshot is a ~2s round trip and the slow-endpoint breaker (`MEDIA_MPV_SLOW_MS=700`
in the machine-local env) trips on nearly every one, so a 4-second playing window
is usually missed and the popup reads blank. Long replies will show; short ones
will not.

Options, cheapest first:
1. Exempt the **active speech socket** from the breaker — it is now the control
   and display path, not the policy chatter the breaker was built to drop.
2. Raise `MEDIA_MPV_SLOW_MS` for that endpoint specifically.
3. Have `say.sh` emit progress lines (it already emits `DURATION`), so display
   costs nothing — but that reintroduces extrapolation, which is what the
   refactor removed. Prefer 1.

## Gotchas that cost time tonight

- **`python - <<PY` with piped stdin**: the heredoc wins; the script reads no
  text and renders silence. Pass text as a file.
- **Heredocs inside `ssh '...'` from zsh** mangle quoting — write the file
  locally and `scp` it.
- **`pkill -f <pattern>`** matches your own shell if the pattern appears in its
  command line. Filter on `/proc/<pid>/comm`.
- **Duplicate keys in `agent-media.env`**: the loader fills only *unset* vars, so
  the **first** occurrence wins and later ones are silently inert. This is why
  the lane switched but the target didn't.
- **Inline comments become part of the value** — `FOO=bar  # note` sets a
  60-character target name. There's now a warning in the env file.
- **`Environment=` in systemd doesn't expand variables**; `ExecStart=` does.
- **ssh `ControlMaster` can go half-dead**: `-O check` says "Master running"
  while refusing every session. `media-lane`'s `phone_ssh()` self-heals it.
