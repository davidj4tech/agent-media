## Updates (19 Oct 2026)

All five bridges are kept current by `agent-bridge-update` (agent-config
bf75e8f; timer `agent-bridge-update.timer`, Wednesdays 04:30). gmessages,
meta, instagram and whatsapp install mautrix's release binaries on their
own, each checked against the release's `sha256sums.txt`. Teams is built
from the fork's newest tag and **staged**: the `bridge-update.msteams`
alert lists the new commits, and `agent-bridge-update install msteams`
puts it in (David's choice: Teams asks first). Every install keeps
`*.prev` copies of the binary, databases and config, and rolls back if
"Bridge started" is not logged within 60 s. Run `agent-bridge-update
status` to see the versions. First run: gmessages, meta and instagram
went from v26.09 to v26.10.
